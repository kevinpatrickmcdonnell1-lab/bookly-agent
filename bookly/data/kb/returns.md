# Returns and refunds

## Return window {#window}
Unread physical books (paperbacks, hardcovers and box sets) can be returned for a full refund within 30 days of delivery. Ebooks that have not been downloaded can also be refunded within 30 days. Books that have been read can't be returned for a refund, except staff picks under the Bookseller's Guarantee. Refunds go back to the original payment method within 5 to 7 business days.

## Damaged or wrong items {#damaged}
If a book arrives damaged, or we sent the wrong item, we refund it in full, no questions asked and with no time limit. You don't need to send the damaged book back.

## Returns that need approval {#approval}
A bookseller reviews any return over $75, and any customer's fourth return within 90 days, before it is processed. This usually takes less than one business day.

## One return per item {#one-per-item}
Each item can be returned once. If an item has already been returned, we can't process a second return for it.

## How to send a book back {#how}
Once a return is confirmed we email a prepaid return label. Drop the parcel at any post office within 14 days.
