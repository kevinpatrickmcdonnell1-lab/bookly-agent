How these evals work

Each scenario is a scripted customer conversation, run against the real models on a fresh copy of the database. It passes only if the agent did the right thing: the refund it issued, the ticket it opened, the tools it called and when. Wording isn't graded, except where a reply has to contain a specific fact.
